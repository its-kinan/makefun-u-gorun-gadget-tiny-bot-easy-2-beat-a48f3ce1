A tiny trend-following paper-trading bot for hourly Solana prices. It holds a symbol only while its fast EMA (12 bars) sits above its slow EMA (30 bars), confirmed for 2 bars, equal-weights the trending names with a 20% cap each, and sits in USDC otherwise — built to beat buy-and-hold by staying out of broad slides and riding uptrends.

## Run it

```sh
node main.ts
```
